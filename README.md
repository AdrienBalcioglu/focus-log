# Focus Log

A focus timer that asks what you got done, and turns the answers into a log of your day.

**[Try it live](https://adrienbalcioglu.github.io/focus-log/)**

## Features

- 25, 50, 15 minutes or a custom duration, with pause
- When the timer rings, one question: what did you get done?
- A log per day with total focus time, ready to copy into a status update
- The countdown survives a reload or a sleeping tab

## Usage

Open `index.html` in a browser. There is nothing to install and nothing to build.

Everything is saved in the browser's local storage. No account, no API key, no server: nothing leaves your machine.

## Stack

HTML, CSS and JavaScript in a single file. No dependency.
